# Адаптивная система строительства
Этот проект содержит систему строительства с возможностью быстрой модификации и расширения

## Используемые технологии
- **Unity**: Игровой движок.
- **C#**: Основной язык программирования.
- **DOTween**: Библиотека для создания плавных анимаций в Runtime.
- **Zenject**: Библиотека DI для Unity.
- **UniRx**: Библиотека для реактивного программирования в Unity.

## Возможности и управление
- Перемещение персонажа осуществляется на `WASD`, а движение камерой при помощи `мыши`.
- При нажатии `ЛКМ` на объекте он притягивается к игроку и фикисруется на нем.
- После притягивания объекта нажатие `ПКМ` позволяет бросить объект, а нажатие `ЛКМ` фиксирует объект на допустимой поверхности (`фантом` показывает место, куда можно разместить объект).
- После притягивания объекта появляется `фантом` объекта, который показывает допустимое расположение и поворот (`фантом` можно крутить колесиком мыши)
- `Куб` можно расположить на полу и другом кубе.
- `Сферу` можно расположить на стене.
- Запрещено располагать предметы внутри других объектов и в воздухе.
- Если поблизости нет поверхности, на которую можно расположить объект, его `фантом` парит в воздухе.
